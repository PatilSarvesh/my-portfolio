# Sarvesh Patil — Backend Systems Portfolio

The portfolio for [Sarvesh Patil](https://github.com/PatilSarvesh), redesigned around backend engineering, cloud-native systems, and developer infrastructure.

The content is kept intentionally close to the current GitHub profile: no generic starter projects, no old security positioning, and no claims beyond the systems and direction currently being built.

The active page is the **Quiet Systems Index**: a compact engineering dossier that presents each project as problem → solution → status, keeps experience easy to scan, and treats Python/AWS backend work as the primary story. It includes a persisted light/night theme switch with contrast-safe color tokens.

The previous command-line direction is preserved as a rollback copy in `src/App.commandline.js`, `src/App.commandline.css`, and `src/index.commandline.css`. The Architecture Atlas direction is also preserved in `src/App.atlas.js`, `src/App.atlas.css`, and `src/index.atlas.css`. Earlier explorations remain in `src/App.field-notes.css`, `src/App.editorial.css`, and `src/App.workbench.css`.

## Featured systems

- [AgentCargo](https://github.com/PatilSarvesh/AgentCargo) — cross-agent registry and package manager for reusable AI-agent skills.
- [Bridge](https://github.com/PatilSarvesh/Bridge) — shared specification and decision control plane for teams working with AI agents.
- [ShortUrl](https://github.com/PatilSarvesh/ShortUrl) — .NET 8 URL-shortening product with custom links, expiry, and redirect analytics.
- [CodeFusion](https://github.com/PatilSarvesh/CodeFusion) — developer toolbox for data conversion, validation, inspection, and workflows.

## Run locally

    npm install
    npm start

The app runs at [http://localhost:3000](http://localhost:3000) by default. To use the current local preview port, run `PORT=3003 npm start` and open [http://localhost:3003](http://localhost:3003).

## Build

    npm run build
